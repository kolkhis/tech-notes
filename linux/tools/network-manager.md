# NetworkManager

NetworkManager is the configuration tool for networking on RedHat-based Linux
systems.

Two tools are primarily used to interact with NetworkManager.  

1. `nmcli`: The NetworkManager CLI (command line interface).  
2. `nmtui`: A TUI (text user interface) for managing NetworkManager.  

Both do the same thing, just have different interfaces.  

The `nmcli` tool is ideal for scripting, as it doesn't require real-time user
input and can perform multiple operations in a single command.  

The `nmtui` tool is ideal when the user wants a nicer, user-friendly interface
to use to perform the same operations.
